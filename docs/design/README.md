# デザインアセット

現行のブランドアセットは `public/images/` で管理する。ここにはアプリが直接配信するSVGと、そこから生成したPNGだけを置く。

過去のデザインは `docs/design/archive/` に保管する。アーカイブ内のファイルは参考資料であり、アプリから参照しない。

## 現行アセット

- `public/images/lexi-logotype.svg`: ヘッダーとログイン画面で使用する文字ロゴ
- `public/images/lexi-symbol.svg`: faviconとアプリアイコンの元データ
- `public/images/favicon.png`: 64pxの派生画像
- `public/images/icon-192.png`: 192pxの派生画像
- `public/images/icon-512.png`: 512pxの派生画像
